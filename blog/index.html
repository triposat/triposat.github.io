SSO enforcement for enterprise workspaces

2026-11-25 · release

Workspace owners can now require SAML SSO for every member. Members who sign in with a password get a 7-day grace period before access switches to SSO only.

Deprecating the v1 REST endpoints

2026-11-24 · release

The v1 REST endpoints stop accepting requests on March 31. Calls to v1 already return a Sunset header, and the migration guide maps every v1 route to its v2 equivalent.

Usage-based pricing replaces seat plans

2026-11-20 · release

From January, every plan bills per million events instead of per seat. Teams under 5M events a month pay less, and nothing changes for existing annual contracts.

Audit log API in public beta

2026-10-29 · release

The audit log API returns every admin action in your workspace with the actor, IP address, and before-and-after values. It's free on every plan during the beta.

Migrating to SDK v3

2026-10-14 · guides

SDK v3 drops Python 3.9 support and replaces the sync client with an async-first design. Most projects need 2 changes: the import path and the client constructor.

EU data residency is now available

2026-10-01 · release

Workspaces created in the EU region now store events, exports, and backups in Frankfurt. Existing workspaces can migrate from the settings page without downtime.
