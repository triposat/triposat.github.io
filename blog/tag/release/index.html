Audit log API in public beta

The audit log API returns every admin action in your workspace with the actor, IP address, and before-and-after values. It's free on every plan during the beta.

Batch exports let you pull up to 50K events per job as Parquet or CSV. Jobs run in the background and post a signed download link to your webhook when they finish.
